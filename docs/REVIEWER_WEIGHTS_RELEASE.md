# Release scope and scientific checkpoint mapping

This clean repository's release scope is exactly one original CNN–ViT selected
EMA state,not an eight-model package. [MODEL_WEIGHTS.md](MODEL_WEIGHTS.md) records
the approved identity,alias,distribution scope and actual download-verification
status. Source licensing and dataset access are separate.

All8main and18ablation identities remain in their frozen scientific manifests.
CNN–ViT is original EMA58(alias `last.pth`),LISTER113,SVTRv2156. Never rescore a
checkpoint directory,replace a selected state with a terminal one,or reserialize
weights to force compatibility. A private path map resolves approved external
files;normal complete-cohort dataset/weight guards are unchanged.

The original GPU compatibility campaign established model loading and execution,
not independent numerical table reproduction. The new reader entrypoint needs
only the proposed model state and can demonstrate synthetic F1inference on CPU.
Unavailable baselines and other states prevent claiming complete reader access to
Tables1–5. No baseline/student/other-seed/ablation binary is uploaded here.

Final manuscript and response-letter code-availability statements will be updated
separately by the authors only after the actual public repository and approved
asset download have been independently verified.
